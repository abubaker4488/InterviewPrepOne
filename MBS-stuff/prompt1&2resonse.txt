## D. Most business-critical project

**mbs-app-API (com.lumen:SpringBootMBS / `MbsApi`)** is the most business-critical project, supported by code-anchored evidence:

1. **It is the only system of record API the GUI talks to.** The GUI's billing, payments, adjustments, OCC, expense, reference-table, and approval flows all read `api.url` (`…/MbsApi/`) and invoke this service — six distinct GUI files inject `@Value("${api.url}")` (BNCController.java, OCCController.java, ExpenseController.java, ReferenceTableController.java, ApprovalServiceImpl.java, BillBalHistoryServiceImpl.java). If `MbsApi` is down, the GUI loses its core billing flows.
2. **It owns the billing domain logic.** Top-level packages are `billingValidateCreate`, `customerBilling`, `customerPaymentInfo`, `PostPayment`, `invoiceCancel` — i.e., bill validation/creation, customer billing, payments, post-payment, invoice cancellation ([list_dir mbs-app-API/src/main/java/com/lumen/mbs](mbs-app-API/src/main/java/com/lumen/mbs)).
3. **It is wired to all four Oracle environments** (`dev`, `test`, `preprod`, `prod`) in application.properties, including production credentials — indicating it is the live billing backend.
4. **The GUI is a presentation layer on top of it.** GUI's `MBSApplication` boots primarily to register a `RestTemplate` and a JSP `ViewResolver` (MBSApplication.java); its business value is exposing `MbsApi` to end users.
5. **atc is functionally isolated** (auth + engineer/project lookup + Excel ingestion) and not in the billing data path.

Summary: ATC is a standalone React + Spring Boot 3 / Java 17 app with no link to the MBS stack; the MBS stack is a two-tier Spring Boot 2.x / Java 8 system where **mbs-app-GUI (JSP)** front-ends **mbs-app-API** over HTTP and publishes to ActiveMQ, with mbs-app-API being the billing system of record.

## High Level Design — Lumen MBS Telecom Billing Platform

---

### 1. Overall Business Purpose

Evidence source: controller names, model names, JSP screens, API endpoints, and database schemas across all three projects.

This workspace is the **Management Billing System (MBS)** — a telecom billing platform operated by Lumen Technologies (formerly CenturyLink/CTL). It manages end-to-end billing lifecycle for enterprise telecom customers:

- **Bill pull and computation** — pulling invoices from source systems, computing charges, taxes, adjustments
- **Customer billing management** — customer search, invoice display, PDF bill generation
- **Payment processing** — posting payments (debit card, credit card, cheque, manual), payment history
- **Billing adjustments** — adjusting invoices with phrase codes, inter/intra amounts, OCC (One-Time Charges)
- **Invoice cancellation** — cancelling invoices and reversing bill balance history
- **Financial approval workflows** — delegated approvals, approval limits
- **Expense management** — expense vouchers, computations, service rates
- **Reference data management** — product service details, rates, tax rates, state/tax exemptions
- **Canned report generation** — PDF and Excel billing reports
- **Market messaging** — operator messages attached to billing cycles
- **Capital project tracking (ATC)** — a separate internal tool for engineers to track CPPM (Capital Project Portfolio Management) project data ingested from Excel files
